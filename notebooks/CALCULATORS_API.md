# QED Numeric Calculators (JIT Core)

Пакет `QED`Numeric`Calculators`` содержит низкоуровневые, высокооптимизированные численные функции для расчета сверхпроводящих квантовых схем. Архитектура пакета построена вокруг концепции разделения статических (вычисляемых один раз) и динамических (вычисляемых для каждой рабочей точки) величин.

## Ключевые концепции и нюансы

1. **JIT-Компиляция (C-Target):** Самые тяжелые алгебраические выражения (градиент, гессиан, матрица обратной индуктивности) транслируются в C-код. Все JIT-движки принимают строго плоские массивы чисел (PackedArrays) вещественного типа.
2. **Обезразмеривание энергии и потока:** Для численной стабильности алгоритма Ньютона внутри JIT-движков энергия масштабируется на квант $E_{scale} = h \cdot 1 \text{ ГГц}$, а магнитный поток переводится в фазу делением на $\Phi_0$. Сами функции-обертки прозрачно конвертируют размерности туда и обратно.
3. **Плавающая земля (Floating Ground):** Для спектральных расчетов (плазмоны) используется редуцированная матрица $N \times N$ (где узел `GroundNode` исключен). Для расчета S-матриц матрица динамически разворачивается до полной $(N+1) \times (N+1)$ для соблюдения правил Кирхгофа.

## Фаза 1.1: Генерация JIT-движков и Статика

### `CalcCompiledEngines`
Генерирует скомпилированные на C функции для поиска равновесия и расчета динамических матриц. 
* **Сигнатура:** `CalcCompiledEngines[analytical, fluxSymbols, paramSymbols]`
* **Возвращает:** Список из трех JIT-движков `{fastGrad, fastHess, fastLInv}`.
* **Нюансы:** Функция автоматически извлекает константы (Планка, заряд, $\Phi_0$) и подставляет их до компиляции. Включает агрессивную оптимизацию общих подвыражений (CSE). Вызов этой функции занимает $\sim 0.1-0.3$ сек, поэтому она должна вызываться строго один раз при инициализации модели.

### `CalcStaticMatrices`
Вычисляет матрицу емкостей $C$ и её обратную $C^{-1}$ для редуцированной схемы.
* **Сигнатура:** `CalcStaticMatrices[analytical, baseRules]`
* **Возвращает:** Список численных матриц `{cNum, invCNum}`.
* **Нюансы:** `baseRules` не должны содержать потоки равновесия. Матрицы имеют размер $N \times N$.

## Фаза 1.2: Блок Равновесия (Equilibrium)

### `CalcEquilibrium`
Мгновенно находит локальный минимум потенциальной энергии, стартуя из переданной точки.
* **Сигнатура:** `CalcEquilibrium[{fastGrad, fastHess, ...}, guess, paramVector]`
* **Возвращает:** `PackedArray` равновесных потоков (`phiMin`) в Веберах.
* **Нюансы:** * `guess` должен быть в Веберах.
  * Внутри использует метод Ньютона. Защищен от символьного парсинга `FindRoot`.
  * Функция **не делает** homotopy continuation. Она предназначена для "атомарного" шага (скорость $\sim 0.7$ мс). Цикл continuation реализуется на уровне менеджера свипов.

## Фаза 1.3: Динамика и Спектр

### `CalcSystemMatrices`
Формирует матрицу обратной индуктивности $L^{-1}$ для заданного вектора равновесных потоков.
* **Сигнатура:** `CalcSystemMatrices[fastLInv, phiMin, paramVector]`
* **Возвращает:** `Association` с ключом `"InverseInductance"`.
* **Нюансы:** Использует третий JIT-движок. В будущем сюда будут добавлены компилированные генераторы операторов напряжения и заряда. Возвращает строго `PackedArray`.

### `CalcEigenSystem`
Решает обобщенную задачу на собственные значения и возвращает частоты плазмонов.
* **Сигнатура:** `CalcEigenSystem[invCNum, invLNum]`
* **Возвращает:** `Association` с ключами `"Frequencies"` (в рад/с) и `"EigenVectors"`.
* **Нюансы:** Извлекает частоты как корни из собственных значений произведения $C^{-1} \cdot L^{-1}$. Включает защиту от комплексных частот для нестабильных мод (седловых точек). Массивы отсортированы по возрастанию действительной части частоты.

## Фаза 1.4: Матрицы Рассеяния (Scattering)

### `CalcSMatrixNumeric`
Собирает Y-матрицу схемы, применяет Шуровское исключение внутренних узлов и преобразует в S-матрицу.
* **Сигнатура:** `CalcSMatrixNumeric[omega, cNum, invLNum, portIndices, z0]`
* **Возвращает:** Матрицу $S$ (размером $P \times P$, где $P$ — количество портов) с комплексными числами.
* **Нюансы:**
  * `omega` задается в рад/с.
  * Внутри функции происходит развертка матриц `cNum` и `invLNum` до $(N+1) \times (N+1)$ для добавления плавающей земли (индекс $N+1$).
  * Для Шуровского исключения используется высокооптимизированный `LinearSolve` (LAPACK/MKL), а не аналитический `Inverse`. Производительность составляет $\sim 200$ микросекунд на точку.
